## Description
Interact with local p2p network connections.

## Command

```console
Usage: humanity net SUBCOMMAND
```

## Subcommands

 - [humanity net connect](connect.md) start a new connection to a peer

 - [humanity net disconnect](disconnect.md) close an existing connection

 - [humanity net status](status.md) status of existing connection

 - [humanity net peers](peers.md) status of all existing peers
