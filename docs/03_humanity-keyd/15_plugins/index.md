## Overview

Plugins extend the core functionality implemented in `humanity-keyd`. For information on specific plugins, just select from the list below:

* [`http_plugin`](../../01_humanityd/03_plugins/http_plugin/index.md)
* [`wallet_api_plugin`](wallet_api_plugin/index.md)
* [`wallet_plugin`](wallet_plugin/index.md)

[[info | humanity-keyd is modular]]
| Plugins add incremental functionality to `humanity-keyd`. Unlike runtime plugins, `humanity-keyd` plugins are built at compile-time.
